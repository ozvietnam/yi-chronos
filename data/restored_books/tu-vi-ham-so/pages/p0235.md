**Xương Khúc Liêm Kình Đà**: Tai nạn khủng khiếp, nếu không cũng bị tù tội. Nếu đại hạn xấu thì khó thoát chết.

### Ý Nghĩa Vật Dụng Của Các Sao

| Tên Sao | Vật Dụng |
| :--- | :--- |
| **Thiên Y** | Quân áo: Thiên Y, Đào, Hồng Quần áo đẹp, sang trọng |
| **Hồng Loan** | Vải vóc: Tam Thai, Bát Tọa Bàn ghế, tủ giường, đồ đạc |
| **Thai Tọa, Khốc Hư** | Đồ đạc trong nhà bị mối mọt |
| **Thiên Cơ** | Máy móc: Thiên Mã Xe cơ khí, hư máy móc |
| **Thiên Hình** | Dao, kéo, binh khí |
| **Kình Dương** | Tràng, đục |
| **Thiên Tướng** | Bút |
| **Văn Xương** | Sách vở: Quang Quý Bài vở (tài liệu) |
| **Thiên Khôi, Thiên Việt** | Văn bằng, nghị định, giấy khen |
| **Vũ, Văn Khúc** | Tấu Thư Nhạc khí: Chuông, nhạc ngựa |
