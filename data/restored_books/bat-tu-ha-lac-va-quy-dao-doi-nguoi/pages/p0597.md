## Bảng Năm Hành Gặp Quẻ

### **Mệnh Kim**
| Địa Chi | Can Giáp | Nạp Âm | Ý nghĩa gặp quẻ |
| :--- | :--- | :--- | :--- |
| **Canh, Tân, Thân, Dậu** | **Kim** | **Kim** | **Kiến:** Phú quý. |
| | | | **Khám:** Bềng bênh, chìm nổi. |
| | | | **Cấn:** Nên ẩn cư. |
| | | | **Chấn:** Có điều sở đắc, tốt. |
| | | | **Tốn** (Gió): Xuân Hạ mát mẻ; Thu Đông lạnh lùng. |
| | | | **Ly:** Nghịch chiều trong hành động. |
| | | | **Khôn:** Được phúc lành. |
| | | | **Đoài:** Đặc địa, tốt. |

### **Mệnh Mộc**
| Địa Chi | Can Giáp | Nạp Âm | Ý nghĩa gặp quẻ |
| :--- | :--- | :--- | :--- |
| **Giáp, Ất, Dần, Mão** | **Mộc** | **Mộc** | **Kiến:** Nhiều hão huyền, ít thực tế. |
| | | | **Khám:** Hăm, mắc kẹt, không làm lớn được, không lâu bên được. |
| | | | **Cấn:** Tốt vẻ Xuân, Hạ, bất lợi về Thu, Đông. |
| | | | **Chấn:** Vinh hoa. |
| | | | **Tốn** (Gió): Tuổi nhỏ hay bị đào động, bấp bênh trắc trở, lo âu. Không tự chủ, hình tĩnh. |
| | | | **Ly:** Hương thơm, sắc tươi bị tổn thiệt. |
| | | | **Khôn:** Phải đợi thời, rồi mới phất đạt. |
| | | | **Đoài:** Giữa mùa Thu mới khởi sắc. |

### **Mệnh Thủy**
| Địa Chi | Can Giáp | Nạp Âm | Ý nghĩa gặp quẻ |
| :--- | :--- | :--- | :--- |
| **Nhâm, Quý, Hợi, Tý** | **Thủy** | **Thủy** | **Kiến:** Như có suối nước chảy. Sẽ giáp thời cơ phát đạt. |
| | | | **Khám:** Hãm, nên lúc lành lúc dữ không định trước được. |
| | | | **Cấn:** Có hiểm trở, khó khăn. |
| | | | **Chấn:** Cuộc đời như nước chảy xuôi dòng, nhưng chẳng được nhàn hạ. |
| | | | **Tốn** (Gió): Sống bấp bênh kỳ. Về các mùa Thu, Đông có điều đáng ngại. |
| | | | **Ly:** Tranh đấu khắc khổ. Thành có bại có. |
| | | | **Khôn:** Nhu thuận, nhàn nhã. |
| | | | **Đoài:** Như nguồn nước chảy đồi đào. Mọi việc hanh thông. |
