## Số theo Hà Đồ của Địa Chỉ

*   **Chính Bắc:** Hợi - Thuộc Thủy (số 1-6)
*   **Chính Nam:** Ngọ - Thuộc Hỏa (số 2-7)
*   **Chính Đông:** Dần - Thuộc Mộc (số 3-8)
*   **Chính Tây:** Dậu - Thuộc Kim (số 4-9)
*   **Tứ Góc:** Thìn - Tuất - Sửu - Mùi - Thuộc Thổ (số 5-10).

### Tìm Quẻ Nguyệt Lệnh của Tháng Sinh
(Để biết Âm Dương tiêu trưởng của Tiết Khí tương ứng)

| Số Hè Lạc | Nguyệt Lệnh | Quả Quẻ theo Âm Dương |
| :---: | :---: | :---: |
| **Đầng Nhân, Đại Tổng** | **Số Âm:** Thái Hữu, Cổ, Ly, LẬP XUÂN (Dương trung) | Tương Sinh (Hàm, Hằng, Tiên): VŨ THUẤV bình là tốt, là Ký Tế thuận thời. |
| | **Số Dương lớn:** Đại Quá, Tấn | HÌNH TRẬP và Hai: hơn số Âm mọi tiết Tương Khắc (Khuê, Cách, Tiểu): XUÂN PHẪN: là thuận thời. |
| | **Số Dương lớn hơn:** Quá | Quẻ Lý, Quẻ Trình: THANH MINH: số Âm là thuận thời. Nếu quá ứ là nghịch số. |
| | **Số Dương cự:** | Quẻ Cấn, Quẻ Tôn trưởng: số Âm ít là thuận. |
| | | Quẻ Dự, Quả Số Âm mới sinh: am Tương Khắc (Khôn, Quẻ Lữ): số Dương nhiều là thuận. |
