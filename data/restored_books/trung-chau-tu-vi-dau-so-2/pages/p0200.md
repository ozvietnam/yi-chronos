“Thái Dương, Thiên Lương” ở hai cung Mão hoặc Dậu

“Thái Dương, Thiên Lương” đồng độ ở hai cung Mão hoặc Dậu, ắt sẽ tương hội với Thái Âm, và tương hội với “Thiên Đồng, Cự Môn” mượn sao an cung, đối cung thì vô chính diệu. (Xem hình 33, 34)

### Hình 33: So sánh các vị trí
| Cung | Sao/Vị trí | Tình trạng |
| :--- | :--- | :--- |
| **Tật Ách** | Thiên Phủ miếu | “Thái Dương nhàn” |
| **Mệnh** | Dậu | Liêm Trinh vượng |
| **Thiên Di** | Mão | “Vô chính diệu Thất Sát miều” |
| **Phụ Mẫu** | Tuất | Giao Hữu Dân |
| **Quan Lộc** | Sửu | Sự Nghiệp Sửu |
| **Điền Trạch** | Tí | Điền Trạch Tí |
| **Phúc Đức** | Ngọ | Phúc Đức Hội |
| **Tài Bạch** | Mùi | Thái Âm hãm Tham Lang vượng “Thiên Đồng hãm” |
| **Tử Tức** | Thân | Vũ Khúc bình |
| **Phu Thê** | Dậu | Cự Môn hãm Thiên Tướng miếu |
| **Huynh Đệ** | Thìn | (Không ghi rõ) |
