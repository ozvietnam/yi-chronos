## 4.1.6. “Thiên Đồng, Cự Môn” ở hai cung Sửu hoặc Mùi

“Thiên Đồng, Cự Môn” đồng độ ở hai cung Sửu hoặc Mùi, cung tam hợp là Thiên Cơ độc tọa, và “Thái Dương, Thiên Lương” mượn sao an cung. (Xem hình 27, 28)

### Hình 27: Phân tích vị trí các sao
| Cung | Sao tại cung | Mô tả chi tiết |
| :--- | :--- | :--- |
| **Phu Thê** | R Tị | - |
| **Tật Ách** | [Huyền thoại] | - |
| **Huynh Đệ** | Ngọ | - |
| **Mệnh** | Mùi | - |
| **Phụ Mẫu** | Thân | Thái Âm hãm: Tham Lang vượng, Thiên Đồng hãm, Vũ Khúc bình. Cự Môn hãm, “Thiên Tướng miếu”. |

### Hình 28: Phân tích vị trí các sao
| Cung | Sao tại cung | Mô tả chi tiết |
| :--- | :--- | :--- |
| **Tài Bạch** | Tị | - |
| **Thiên Di** | [Huyền thoại] | - |
| **Tật Ách** | Dần | - |
| **Phụ Mẫu** | Sửu | - |
| **Giao Hữu** | Tỵ | - |
| **Sự Nghiệp** | Hợi | Phá Quân hãm, Vô chính diệu Từ Vị bình, “Thiên Cơ bình”. |

***

Muốn luận đoán bản chất của “Thiên Đồng, Cự Môn” ở hai cung này, cẩn phải chú ý tình cảm của tính hệ này, xem thuộc sắc.
