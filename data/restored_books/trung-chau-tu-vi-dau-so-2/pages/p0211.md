4.1.10. Thiên Cơ độc tọa ở hai cung Tị hoặc Hợi

Thiên Cơ độc tọa ở hai cung Tị, Hợi ắt sẽ đối nhau với Thái Âm. Cung tam hợp là “Thiên Đồng, Cự Môn”, và “Thái Dương, Thiên Lương” mượn sao an cung. (Xem hình 39, 40)

***

### Phân tích các vị trí cung (Trích lục từ H.39 & H.40)

**Bảng tổng hợp các Cung và Chính Tinh:**

| Cung | Mệnh/Vị trí | Chính Tinh | Phụ Tinh/Miếu Vượng |
| :--- | :--- | :--- | :--- |
| **Mệnh** | Hợi | Thiên Cơ | Bình, Từ, Vì (Thiên Cơ bình) |
| **Phụ Mẫu** | Tý | - | - |
| **Thiên Di** | Hợi | Vũ Khúc | Nhân, Thiên Đồng hãm, Tham Lang vượng, Thái Âm miếu |
| **Tài Bạch** | Sửu | - | - |
| **Tật Ách** | Tí | - | - |
| **Thiên Trụ** | Mão | - | - |
| **Quan Lộc** | Dậu | - | - |
| **Nô Bộc** | Thìn | - | - |
| **Phúc Đức** | Mùi | - | - |
| **Điền Trạch** | Thân | - | - |
| **Phu Thê** | Dậu | - | - |

**Chi tiết các cung khác:**

*   **Thiên Cơ tại Mệnh (Hợi):** Thiên Cơ bình, Từ, Vì.
*   **Cung Quan Lộc (Mão):** Hữu, Tuất.
*   **Cung Nô Bộc (Thìn):** Sự Nghiệp, Dậu.
*   **Cung Phúc Đức (Sửu):** -
*   **Cung Phụ Mẫu (Tí):** -
*   **Cung Điền Trạch (Thân):** -

**Các cung có sao đặc biệt:**

*   **Thiên Tướng/Liêm Trinh:** Thiên Tướng hãm, Liêm Trinh vượng.
*   **Thái Dương:** Thái Dương miếu.
*   **Thiên Lương:** Thiên Lương miểu.
*   **Cự Môn:** Cự Môn hãm.
