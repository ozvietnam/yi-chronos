### 4.3.12. Thiên Cơ độc tọa ở hai cung Sửu hoặc Mùi

Thiên Cơ độc tọa ở hai cung Sửu hoặc Mùi, đối cung là **Thiên Lương**, cung tam hợp là **Cự Môn** độc tọa và **Thiên Đồng** độc tọa. (Xem hình 105, 106).

Muốn luận đoán bản chất của Thiên Cơ ở hai cung này cần phải phân biệt xem nó là “tiến bộ”, hay là “lạc hậu”.

***

#### Sơ đồ H.105: Sự Nghiệp và các Cung khác

| CUNG | CHÍNH TINH/SỰ VỊ TRÍ |
| :--- | :--- |
| **PHU THÊ** | Tị |
| **HUYNH ĐỆ** | Ngọ |
| **MỆNH** | Mùi |
| **PHỤ MẪU** | Mão |
| **THÂN** | Thân |

**Thiên Cơ** ở Mùi, **Thái Dương** vương **Phá Quân** miếu.

**Thiên Phủ** bình.

**TỬ NỮ** thìn: **Phúc Đức** Dấu.

**Vũ Khúc** miếu, **Thái Âm** vượng.

**TÀI BẠCH** Mão, **Điền Trạch** Tuất.

**Thiên Đồng** miếu, **Tham Lang** miếu.

| CUNG | CHÍNH TINH/SỰ VỊ TRÍ |
| :--- | :--- |
| **TẬT ÁCH** | Dần |
| **THIÊN DI** | Sửu |
| **GIAO HỮU** | Tị |
| **SỰ NGHIỆP** | Hợi |

**Thất Sát** miếu, **Thiên Lương** vượng. **Liêm Trinh** bình. **Cự Môn** vượng.

**Thiên Tướng** miểu.

***

#### Sơ đồ H.10: Các Cung khác (Chi tiết)

| CUNG | CHÍNH TINH/SỰ VỊ TRÍ |
| :--- | :--- |
| **SỰ NGHIỆP** | Tị (**Giao Hữu**) |
| **THIÊN DI** | Mùi |
| **TẬT ÁCH** | Thân |

**Cự Môn** bình. **Liêm Trinh** cưnh. **Thiên Lương** vượng. **Thất Sát** miết. **Thiên Tướng** vượng.

**ĐIỀN TRẠCH** Thìn, **TÀI BẠCH** Dậu.

**Tham Lang** miểu. **Thiên Đồng** đi.

**PHÚC ĐỨC** Mão: Từ Nữ Tuất.

**Thái Âm** hớm. **Vũ Khúc** miễu.

| CUNG | CHÍNH TINH/SỰ VỊ TRÍ |
| :--- | :--- |
| **PHỤ MẪU** | Đà Nẵng |
| **MỆNH** | Sửu |
| **HUYNH ĐỆ** | Tị |
| **PHU THÊ** | Hợi |

**Từ** vì vương. **Thiên Cơ** hôm. **Phá Quân** miểu.

**Thái Dương** miếu.

**Thiên Phủ** miểu.
