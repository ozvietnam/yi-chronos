# Ke hoach phat trien 1 tuan (2026-05-09 -> 2026-05-15)

## Muc tieu tuan

- On dinh nen tang API + frontend hien tai de chay ben.
- Tu dong hoa pipeline tri thuc 64 que (ingest -> audit -> report).
- Nang chat luong code review va memory handoff de session sau tiep tuc khong mat ngu canh.

- Backend: `api/main.py` la trung tam endpoint, gom universe, luc hao, lien hoa, yi64 text/coverage/audit.
- Core:
  - `core/hexagram.py`, `core/hexagram_texts.py`: da hoan chinh cho 64 que va multi-source.
  - `core/yi64/*`: da co pipeline model/registry/transform, nhung chua noi day du vao flow runtime chinh.
  - `core/chronos.py`: time state + almanac co ban.
- Engine:
  - `engine/luc_hao.py`, `engine/lien_hoa.py`, `engine/scoring.py`, `engine/personal.py`: da co shape endpoint + logic.
- Frontend:
  - `App.vue` + cac page/chuc nang da lien ket.
  - `UniverseCore.vue` van la vung rui ro do 3D interaction (dang tam dung uu tien).
- Test:
  - Da co test cho API, hexagram, yi64 pipeline, luc hao timing.
  - Chua thay test tich hop frontend E2E va perf guard.
