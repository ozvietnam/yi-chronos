## 📊 Tổng kết — 9 quy luật đã wire

### Quy luật 1: Tứ Hóa tại chính tinh Phu Thê
- Tham Lang Hóa Lộc → thiên vật chất
- Vũ Khúc Hóa Lộc → vợ giỏi hơn
- Tham Lang/Vũ Khúc/Liêm Trinh Hóa Kỵ → đại hung
- Thiên Phủ Hóa Khoa → vật chất tăng

### Quy luật 2: "Đào hoa phạm chủ" detection
**Condition (sách 3.x):** Tử-Tham + có sao đào hoa khác đồng cung
- Hồng Loan, Thiên Hỉ, Hàm Trì, Đại Hao, Thiên Diêu, Mộc Dục
- Detected → cảnh báo dục tình
- Không detected → "đa tài đa nghệ, giỏi giao tế, có chủ kiến"

### Quy luật 3: Xương-Khúc rule riêng Tử-Tham
**Rule riêng:** Chỉ Tử-Tham gặp Xương/Khúc mới tăng đào hoa (sao thường thì giảm)
- Check trong cung Phu Thê HOẶC tam phương tứ chính

### Quy luật 4: Tả-Hữu hội chiếu tam phương
**Aggregate:** Phu Thê + đối + 2 tam hợp
- Cần CẢ Tả Phụ + Hữu Bật → "đa tài đa nghệ"
- Chỉ 1 (sao lẻ) → tái hôn / người thứ ba

### Quy luật 5: Đối cung Phu Thê (= Quan Lộc)
- Vô chính diệu → "mượn sao Phu Thê" → sự nghiệp + hôn nhân chia sẻ tinh hệ
- Có chính tinh → 2 cung độc lập

### Quy luật 6: Mệnh chủ paradigm
| Mệnh chủ | Đặc thù |
|---|---|
| Vũ Khúc | Cứng + cô độc → cần vợ MỀM |
| Tham Lang | Đào hoa + ham muốn → cần đối tác tiết chế |
| Cự Môn | Khẩu thiệt → vợ chồng dễ tranh cãi |
| Lộc Tồn | Ích kỷ → cần chia sẻ tài chính |
| Văn Khúc | Đa tài đa cảm → cần hiểu sâu |
| Liêm Trinh | Máu lửa → rối ren tình ái |
| Phá Quân | Đột phá → cùng tinh thần |

### Quy luật 7: Thái Dương / Thái Âm miếu hãm (xem kèm)
**Sách 5.3:** PHẢI xem kèm
- Nam mệnh → xem **Thái Âm** (sao vợ)
- Nữ mệnh → xem **Thái Dương** (sao chồng)
- Miếu/vượng + cát tinh → hôn nhân thuận
- Lạc/hãm + Hóa Kỵ + sát → bất lợi

### Quy luật 8: Đại Vận Cung Phu Thê (8 vận)
**Công thức:** Phu Thê đại vận = Mệnh đại vận - 2 (mod 12)
- Detect Hóa Kỵ trùng điệp → cảnh báo
- Cảnh báo nặng nếu Vũ Khúc/Thái Dương/Liêm Trinh Hóa Kỵ

### Quy luật 9: Lưu Niên Markers
**Sách 3.x:** "Hồng Loan/Thiên Hỉ bay đến cung Mệnh hoặc Phu Thê lưu niên → ứng kỳ kết hôn/thai"
- Scan 10 năm tới
- Return list năm có trigger (Hồng Loan → Mệnh / Phu Thê / Thiên Hỉ → Mệnh / Phu Thê)
