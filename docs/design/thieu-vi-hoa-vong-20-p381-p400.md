### 4. ⭐⭐⭐⭐⭐ **SẮP XẾP 64 QUẺ (Tự Quái Truyện) — luân lý vũ trụ** (p387-390)
**Thượng Kinh** (đạo trời): Càn-Khôn → có vạn vật → Thuần → Mông → Nhu → Tụng → Sư → Tỷ → Tiểu Súc → Lý → Thái → Phủ → Đồng Nhân → Đại Hữu → Khiêm → Dự → Tùy → Cổ → Lâm → Quan → Phệ Hạp → Bí → Bóc → Phục → Vô Vọng → Đại Súc → Di → Đại Quá → Khảm → Ly

**Hạ Kinh** (đạo người): Hàm (vợ chồng) → Hằng → Độn → Đại Tráng → Tấn → Minh Di → Gia Nhân → Khuê → Kiển → Giải → Tổn → Ích → Phu → Cấu → Tụy → Thăng → Khốn → Tỉnh → Cách → Đỉnh → Chấn → Cấn → Tiệm → Quy Muội → Phong → Lữ → Tốn → Đoài → Hoán → Tiết → Trung Phù → Tiểu Quá → Ký Tế → **Vị Tế** (kết thúc bằng "chưa xong" → tuần hoàn vô tận)

> _"Kinh Dịch đến đây là kết thúc, tượng trưng cho đạo trời tuần hoàn mãi, việc ở đời cũng vô cùng vô tận."_

### 5. ⭐⭐⭐⭐⭐ **GIEO QUẺ THEO THỜI GIAN** (p399-400) — paradigm cốt thực hành
**Bước 1 — Quẻ Thượng**: (Năm + Tháng + Ngày) % 8 → Tiên Thiên Bát Quái
**Bước 2 — Quẻ Hạ**: (Năm + Tháng + Ngày + Giờ) % 8 → Tiên Thiên Bát Quái
**Bước 3 — Hào Động**: (Năm + Tháng + Ngày + Giờ) % 6

**Tiên Thiên Bát Quái số**:
| Dư | Quẻ |
|---|---|
| 1 | Càn |
| 2 | Đoài |
| 3 | Ly |
| 4 | Chấn |
| 5 | Tốn |
| 6 | Khảm |
| 7 | Cấn |
| 8/0 | Khôn |

**Ví dụ TVH**: Giờ Sửu (2), ngày 3 tháng 3 nhuận, năm Quý Dậu 1993 (Dậu=10)
- Thượng: 10+3+3 = 16, %8 = 0 → 8 = **Khôn**
- Hạ: 10+3+3+2 = 18, %8 = 2 → **Đoài**
- Hào động: 18%6 = 0 → hào 6
- **Quẻ gốc**: Khôn (trên) + Đoài (dưới) = ĐỊA TRẠCH LÂM, hào 6 động

**3 cách gieo khác**:
- **Số vật đếm được** → quẻ thượng = số, quẻ hạ = số + giờ
- **Số tiếng nghe** (gõ cửa, động vật kêu) → quẻ thượng = số tiếng
- **Chữ số** → quẻ thượng = số chữ chia 2
