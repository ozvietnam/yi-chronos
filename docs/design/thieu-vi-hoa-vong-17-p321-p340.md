## 🎯 5 Paradigm cốt

### 1. ⭐⭐⭐⭐⭐ **BÁT QUÁI ↔ CƠ THỂ — bảng mapping đầy đủ** (p326)
| Bát Quái | Ngoại hành (bên ngoài) | Nội hành (cơ quan) |
|---|---|---|
| **Càn** | Đầu | Phổi |
| **Đoài** | Miệng | Phổi |
| **Ly** | Mắt | TIM |
| **Chấn** | Chân | GAN |
| **Tốn** | Đùi | Mật |
| **Khảm** | Tai | THẬN |
| **Cấn** | Tay | Lá lách (tỳ) |
| **Khôn** | Bụng | Dạ dày |

**Ngũ Hành ↔ Cơ quan**:
- **Thủy** = Thận
- **Mộc** = Gan
- **Hỏa** = Tim
- **Thổ** = Lá lách / Dạ dày
- **Kim** = Phổi

### 2. ⭐⭐⭐⭐ **HÀO QUAN QUỶ + Ngũ Hành → loại bệnh** (p326-327)
| Quan Quỷ | Bệnh + triệu chứng |
|---|---|
| **Thủy** | Thận: ác hàn, mồ hôi trộm, đi tiểu khó |
| **Mộc** | Gan: cảm phong hàn, đau chân, tứ chi khó cử |
| **Hỏa** | Tim: phát nhiệt, miệng khô, lưỡi tưa, nhọt độc |
| **Thổ** | Thần kinh: vàng da, phù thũng, ôn dịch |
| **Kim** | Phổi: ho, run lạnh, thở suyễn đờm, răng |

**Quan Quỷ ở cung nào → bộ phận đó bệnh**:
- Càn → đau ĐẦU
- Cấn → mụn nhọt; biến Thổ Quỷ → phù thũng
- Tốn + Mộc Quỷ biến Kim → thương ĐÙI / đau mắt
- Khôn + Hỏa Quỷ → đau BỤNG; Thủy Quỷ → tả/lỵ; Mộc Quỷ → xoắn ruột; Kim Quỷ → đau ngực sườn
- Chấn → CHÂN: Phi Xà = phù; Bạch Hổ = gãy; Mộc = mỏi tê; Hỏa = mụn nhọt; Kim = gãy/dao đâm; Thủy = phong thấp
- Khảm + Thủy hóa Thổ + Bạch Hổ dương → đái máu; Bạch Hổ âm → đi ngoài máu; Bạch Hổ hình khắc → BỆNH TRĨ

### 3. ⭐⭐⭐⭐ **6 HÀO ↔ 6 PHẦN CƠ THỂ** (p327, Bốc Phệ Nguyên Quỷ)
| Hào | Vị trí |
|---|---|
| 1 (đầu) | Sự BỊ THƯƠNG |
| 2 | Hai CHÂN nặng |
| 3 | THẮT LƯNG (thường nhẹ) |
| 4 | BỤNG, dạ dày, ruột |
| 5 | THẬN yếu, nhiều chướng khí |
| 6 (sáu) | ĐẦU |

### 4. ⭐⭐⭐⭐ **6 LỤC THÂN — Đoán bệnh cho ai dùng dụng thần nào** (p327-328)
| Đoán cho | Dụng thần | Cát tượng | Hung tượng |
|---|---|---|---|
| **Bản thân** | Hào THẾ | Vượng + Tử Tôn động sinh | Quan Quỷ trì Thế + nhập Mộ |
| **Cha mẹ** | Phụ Mẫu | Nhật/Nguyệt sinh phù | Huynh Đệ động → bệnh khó chữa |
| **Con cái** | Tử Tôn | Vượng + Nhật/Nguyệt sinh | Thê Tài động xẹp hơi → bệnh khó dứt |
| **Anh em** | Huynh Đệ | Vượng + Phụ Mẫu sinh | Thê Tài + Quan Quỷ động → chết |
| **Vợ** | Thê Tài | Hóa Tử Tôn + Đế Vượng | Hóa Huynh Đệ → chết |
| **Chồng** | Quan Quỷ | Vượng + Nhật/Nguyệt sinh | Nhập Mộ → xấu |

### 5. ⭐⭐⭐ **QUAN QUỶ phục dưới hào → nguyên nhân bệnh** (p329)
| Phục dưới | Nguyên nhân |
|---|---|
| Thê Tài | Ăn uống / tiền của / "quan hệ vợ chồng" |
| Huynh Đệ | Cãi vã vì nhan sắc / tiền, nhịn ăn |
| Phụ Mẫu | LAO TÂM KHỔ TỨ, kiệt tinh thần |
| Tử Tôn | Say rượu / "quan hệ vợ chồng" quá / thuốc bổ quá nhiều |

**Tiến/Thoái bệnh tình**:
- Quan Quỷ hóa **Tiến** → bệnh NẶNG THÊM
- Quan Quỷ hóa **Thoái** → bệnh GIẢM DẦN
- Quan Quỷ biến Quan Quỷ → vừa cũ vừa mới
- 2 Quan Quỷ kẹp Dụng Thần → không chết cũng HÔN MÊ
- Lục Hợp biến Lục Xung → bệnh nguy kịch
