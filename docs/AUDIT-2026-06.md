## 📋 Toàn bộ phát hiện theo nhóm

### 🧮 Engine — độ chính xác (6 bug, tất cả có bằng chứng)

> **Mẫu số chung:** `core/chronos.py` tính can-chi sai mốc cả **3 trụ** (ngày/tháng/năm) theo 3 kiểu khác nhau. Nên **viết lại phần can-chi bằng sxtwl** (đã có trong stack).

- **#17 🔴🔴 Trụ NĂM + THÁNG sai mốc** (`core/chronos.py:172-173`). Năm đổi tại 1/1 thay vì Lập Xuân (~9% user sai), tháng đổi tại mùng-1 thay vì 節 (~20% sai). Cascade: Tứ Hóa/cục/Mệnh chủ (Tử Vi) + nạp âm/cách cục (Bát Tự). **Nặng nhất.**
- **#12 🔴 Day pillar sai cho người sinh 00:00–06:59** (`chronos.py:167`, `floor(utc.timestamp()/86400)` = ranh giới ngày theo UTC = 07:00 VN). Lan sang Hà Lạc + Lục Hào.
- **#13 🔴 Tử Vi sai cho người sinh 23:00–23:59** (`_cast_chart` / `/tu-vi/cast` bỏ rollover 早子時 → lunar_day lệch → sao Tử Vi an sai cung → cả 14 chính tinh xê dịch).
- **#16 🔴 Hỷ/Kỵ thần đảo ngược** (`dung_than.py` tính quanh dụng thần thay vì nhật chủ → 官殺 bị gán "cát" cho nhật chủ nhược → lời khuyên màu/hướng/nghề ngược, ~30-40% lá số).
- **#14 🔴 Đại Vận khởi-vận sai** (`bat_tu/starting_age.py` đếm tới mốc 15° gồm cả Trung Khí thay vì 節 30° → founder 4 tuổi thay vì ~10).
- **#15 🟡 Trộn 2 hệ lịch âm VN/CN** (`core/lunar_calendar` UTC+7 vs `lich_conversion`/sxtwl UTC+8) — lệch quanh tháng nhuận + flag `lunar_is_leap_month` bị bỏ. Cần chốt 1 hệ.

### 🔒 Security (7)

- **#7 🔴 `/api/yi-publishing/*` hở hoàn toàn** — **hở thật trên live** (không proxy che): guest DELETE sách, trigger OCR/LLM batch tốn tiền.
- **#8 🔴 `/api/tu-vi/analyze` + report-pdf** — guest đọc lá số founder (`_founder` cache) + rò birth data chéo user (query `user_persons` không filter user_id).
- **#3 🔴 7 endpoint founder chưa gate** (`/api/ky-mon/founder-birth-data`, `/api/yi-publishing/*founder*`) — guest đọc ngày sinh/đại vận/lưu niên/synastry.
- **#6 🟠 `/api/ai/*` chưa gate tầng app** — ghi đè API key, đốt key trả phí, sửa prompt. *Giảm nhẹ: live có Traefik basicauth che `/api/ai/`.*
- **#22 🟠 XSS** — 3 `renderMarkdown` (ResearchPanel/KinhDichBrowser/LuuVanDashboard) render `v-html` không escape; ResearchPanel render nội dung web + cho `javascript:` link. 7 component khác escape đúng → bug là không nhất quán (11+ bản copy).
- **#10 🟡 CORS `*` + credentials** (bỏ quên env `YI_CHRONOS_CORS_ORIGINS`) + cookie thiếu `Secure`. *Giảm nhẹ: SameSite=Lax.*
- **#9 🟡 Gating sót** — `/api/yi-hermes/dyad+chat+glossary` (rò social graph founder, đốt token) + `/api/yi-wiki/nhat-ky/*` (guest dùng chung namespace `"founder"` → đọc/xóa nhật ký guest khác).
