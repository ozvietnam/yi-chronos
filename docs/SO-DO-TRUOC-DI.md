## 🎯 Cách dùng catalog (workflow mới)

**Khi anh hỏi 1 chủ đề** (VD: "Đắc Thể của anh"):
1. `GET /api/chu-de-catalog?keyword=đắc thể` → trả về catalog entry
2. Catalog show: Hoàng Tuấn p70-72 (must-read) + cross-refs
3. Em ĐỌC chỉ 3 trang đó + cross-check 1-2 sách khác nếu có
4. Render luận giải tường minh

**Khi anh hỏi paradigm cross-cutting** (VD: "Đức năng thắng số"):
1. `chu_de_id=duc_nang_thang_so` → trả về 3 nguồn cổ
2. NTT quẻ Mông Trình Di + Xuân Cang PBC Thái-Bĩ + Hoàng Tuấn p37
3. Em đọc 3 đoạn ngắn (10 phút) → narrative tường minh
